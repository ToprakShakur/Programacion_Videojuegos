# Proyecto 2D - Práctica 1 (Unity)

##  Descripción
Este proyecto corresponde a la **Práctica 1 de Ayudantía en Unity 2D* donde se introducen conceptos 
básicos de sprites, colisiones y detección de inputs.

##  Requisitos
- Unity Hub instalado.
- Editor de Unity 
- Repositorio del alumno configurado.
- Spritesheet proporcionado o descargado.

##  Pasos para ejecutar
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/ToprakShakur/Programacion_Videojuegos.git ```
2. Abrir Unity Hub y seleccionar el proyecto de la carpeta
	Ayudantia/Practica01/proyecto2D
3. Ejecutar la escena desde el editor 
	Cuando detecta una colision con un objeto imprime en consola "Colision con: Plataforma"
	Detecta inputs basicos: Movimientos izquierda,derecha con las flechas del teclado imprime "Movimiento detectado"
				Salto con barra espaciadora "Slalto detectado"
